## 🌟 Featured & Production Projects

### 🛒 [SyncHub — Multi-Platform E-Commerce Synchronization Engine](https://github.com/aditya072690/SyncHub)
- **Description:** A robust synchronization backend designed to sync inventory, products, and orders across **Shopify, WooCommerce, and Amazon SP-API** via OAuth 2.0, REST APIs, and event-driven webhooks.
- **Key Highlights:**
  - Engineered an asynchronous task pipeline using **Celery 5.x + RabbitMQ**, with dead-letter exchanges, exponential backoff with jitter, and automatic retries for resilient third-party API communication.
  - Implemented concurrency-safe inventory management with **PostgreSQL row-level locking (`select_for_update`)** and atomic transactions to eliminate race conditions and overselling.
  - Engineered unified webhook ingestion with per-platform HMAC-SHA256 signature verification and event deduplication, acknowledging webhooks in **< 2ms**.
  - Built a configurable conflict resolution engine with customizable Source of Truth rules and manual override workflows.
  - Encrypted tokens and secrets at rest using **Fernet (AES-128-CBC + HMAC-SHA256)**, integrated with an intuitive Django admin monitoring panel.
- **Tech Stack:** `Django 5.1` `Django REST Framework` `Celery` `RabbitMQ` `PostgreSQL` `OAuth 2.0` `AWS SNS` `Fernet Encryption`
